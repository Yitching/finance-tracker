# App icon: Lazy coin

The sources for the PNGs in `web/public/`:

- `lazy-coin.svg`: the full icon, used for `pwa-192.png`, `pwa-512.png`, `apple-touch-icon.png` (180) and `favicon.png` (64).
- `lazy-coin-maskable.svg`: the same art scaled to 80% so it fits Android's round mask, used for `pwa-maskable-512.png`.

To change the icon, edit the SVGs and re-export each PNG at its size. Any SVG-to-PNG tool works, e.g. a headless browser screenshot.
